Scarlet ChatBot Factory — Guarded Multi-Agent Architecture

Domain-guarded bots + team-mode agent routing + human handoff

Request Life-cycle

  • 1. Visitor sends message via widget
  • 2. Guard checks domain (4 layers)
  • 3. Out-of-domain → polite refusal
  • 4. In-domain → solo bot or team router
  • 5. LLM answers, history saved to DB

Agent Modes

  • • Solo bot — one guarded specialist
  • • Team mode — orchestrator routes each
  • message to best specialist (lexicon
  • score, Groq tie-break, never dead-ends)
  • • Human handoff — live agent queue +
  • co-pilot for tough conversations

Why it's safe

  • • Every agent path passes the guard first
  • • Classifier default = NO (deny-by-default)
  • • "What is RAG?" / jokes / politics → refused
  • • Legit follow-ups ("price?") still work
  • • Tested live: 10/10 guard, 6/6 HTTP
  • • Ship pipeline: GitHub → Render deploy
